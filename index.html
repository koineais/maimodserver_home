RULES / 安全憲章

透過、飛行(Fly)、各種自動エイム、移動速度変更ツールを含む、全ての不正な外部モジュール・ハッククライアントを禁止します。検知システムがパケット異常を捉え次第、インフラ側でハードウェアアクセス追放（永久BAN）を自動執行します。

External modification architectures or speed factor tools are prohibited. System nodes execute hardware access drops on detection logs.

他のプレイヤーが所有する土地エリアの無断破壊、チェストからの物資窃盗、および迷惑行為を固く禁じます。提供されている土地主張コマンドを使用して拠点を暗号化・保護してください。悪質な違反はログデータより特定され、処分の対象となります。

Griefing inside verified player domains is restricted. Secure territories via internal protection frameworks to anchor asset metrics.
